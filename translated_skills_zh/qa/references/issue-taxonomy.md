# QA 问题分类体系

## 严重程度等级

| 严重程度 | 定义 | 示例 |
|----------|------|------|
| **critical** | 阻塞核心工作流、导致数据丢失，或使应用崩溃 | 提交表单导致错误页面、结账流程损坏、未经确认即删除数据 |
| **high** | 主要功能损坏或无法使用，且没有替代办法 | 搜索返回错误结果、文件上传无提示失败、认证重定向循环 |
| **medium** | 功能可以使用，但存在明显问题，且有替代办法 | 页面加载缓慢（>5s）、缺少表单校验但仍可提交、仅在移动端布局损坏 |
| **low** | 轻微的视觉或打磨问题 | 页脚有错别字、1px 对齐问题、悬停状态不一致 |

## 分类

### 1. 视觉/UI
- 布局损坏（元素重叠、文本被裁切、出现水平滚动条）
- 图片损坏或缺失
- z-index 不正确（元素显示在其他元素后面）
- 字体/颜色不一致
- 动画异常（卡顿、过渡不完整）
- 对齐问题（未对齐网格、间距不均匀）
- 深色模式 / 主题问题

### 2. 功能
- 链接失效（404、目标错误）
- 按钮失效（点击无反应）
- 表单校验（缺失、错误、可绕过）
- 重定向错误
- 状态未持久化（刷新后数据丢失、返回按钮后数据丢失）
- 竞争条件（重复提交、过期数据）
- 搜索返回错误结果或无结果

### 3. UX
- 导航令人困惑（没有面包屑、进入死胡同）
- 缺少加载指示器（用户不知道正在发生什么）
- 交互缓慢（>500ms 且没有反馈）
- 错误信息不明确（“Something went wrong” 但没有细节）
- 执行破坏性操作前没有确认
- 页面之间的交互模式不一致
- 死胡同（没有返回路径、没有下一步操作）

### 4. 内容
- 拼写和语法错误
- 文本过时或不正确
- 遗留占位文本 / lorem ipsum 文本
- 文本被截断（没有省略号或“more”）
- 按钮或表单字段标签错误
- 空状态缺失或信息无帮助

### 5. 性能
- 页面加载缓慢（>3 秒）
- 滚动卡顿（掉帧）
- 布局偏移（加载后内容跳动）
- 网络请求过多（单个页面超过 50 个）
- 大尺寸未优化图片
- 阻塞式 JavaScript（加载期间页面无响应）

### 6. 控制台/错误
- JavaScript 异常（未捕获错误）
- 网络请求失败（4xx、5xx）
- 弃用警告（即将发生中断）
- CORS 错误
- 混合内容警告（HTTPS 页面中加载 HTTP 资源）
- CSP 违规

### 7. 可访问性
- 图片缺少 alt 文本
- 表单输入缺少标签
- 键盘导航损坏（无法用 Tab 切换到元素）
- 焦点陷阱（无法退出模态框或下拉菜单）
- ARIA 属性缺失或错误
- 颜色对比度不足
- 屏幕阅读器无法访问内容

## 逐页探索检查清单

在 QA 会话期间访问的每个页面，都要检查：

1. **视觉扫描** — 获取带标注的截图（`snapshot -i -a -o`）。查找布局问题、损坏图片、对齐问题。
2. **交互元素** — 点击每个按钮、链接和控件。每个元素的行为是否符合其说明？
3. **表单** — 填写并提交。测试空提交、无效数据和边界情况（长文本、特殊字符）。
4. **导航** — 检查所有进入/离开路径。面包屑、返回按钮、深链接、移动端菜单。
5. **状态** — 检查空状态、加载状态、错误状态、完整/溢出状态。
6. **控制台** — 交互后运行 `console --errors`。是否有新的 JS 错误或失败请求？
7. **响应式** — 如有需要，检查移动端和平板视口。
8. **认证边界** — 登出时会发生什么？不同用户角色会怎样？
