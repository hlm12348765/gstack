# gstack 深度分析（review_docs）

本目录包含对 gstack（Claude Code / Codex skill 工作流）的多版本分析，按“先拆解、再批判、再综合”的方式迭代：

- `v1-architecture-notes.md`：结构化拆解（设计理念与机制）。
- `v2-productivity-thesis.md`：为何能大幅提升生产力（超越“代码生成”）。
- `v3-startup-operating-model.md`：YC 工作方式对创业/变革团队的组织启示。
- `final-synthesis.md`：最终整合版（含可执行落地建议与待办）。

## 使用建议

1. 先读 `v1` 了解 gstack 的底层“操作系统”式设计。
2. 再读 `v2` 看它如何改变单位时间产出与风险结构。
3. 最后读 `v3` 与 `final`，将其迁移到你的团队运行机制。
